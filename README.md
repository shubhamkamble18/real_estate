# 🏠 Real Estate Website

A responsive and user-friendly **Real Estate Website** developed using **HTML, CSS, JavaScript, and Bootstrap**. The website is designed to provide users with an easy way to explore and view property listings through a clean and modern interface.

## live demo 
URL - https://shubhamkamble18.github.io/real_estate/

## ✨ Features

* 🏡 Modern real estate homepage
* 🔍 Property search functionality
* 🏠 Property listing cards
* 📄 Property details section
* 📱 Responsive design for mobile, tablet, and desktop
* 🖼️ Property images and information
* 📞 Contact and inquiry section
* 🧭 Responsive navigation bar
* 🎨 Bootstrap-based UI components
* ⚡ JavaScript interactions and dynamic elements

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Custom styling and layout
* **JavaScript** – Interactive functionality
* **Bootstrap** – Responsive design and UI components

## 🎯 Project Objective

The main objective of this project was to create a professional and responsive real estate platform where users can browse properties and view important property information in a simple and attractive interface.
